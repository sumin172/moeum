# 모음 개발 문서

모음은 일상 대화를 사용자 설정 시각에 자동으로 일기로 만드는 서비스다.
이 문서 묶음은 현재 서버 구현과 확정 기획을 설명한다. 구현 기본값과 미확정 정책은 별도로 표시한다.

## 읽는 순서

1. [서비스 기획](PRODUCT.md): 서비스 목적, 사용자 경험, 확정 정책과 확인할 정책.
2. [아키텍처](ARCHITECTURE.md): 모듈 소유권, 데이터 접근, 트랜잭션과 실행 경계.
3. [하루 기록](RECORD_DAY.md): 접수 시각, 마지막 장소의 타임존, 마감과 생성 입력.
4. [대화 계약](CONVERSATION.md): 접수 한도, 응답 순서, 조회와 재시도.
5. [일기 계약](JOURNAL.md): 자동 생성, 구독 수정, 결과 보호와 조회.
6. [실행 역할](WORKER_ROLES.md): 실행 방법, 역할별 자원 상한과 복구.
7. [관측·보존](OBSERVABILITY_RETENTION.md): 로그·메트릭과 작업 정리.
8. [개발 원칙](PRINCIPLES.md): 필수 상태, 자원 재사용, 정리와 검증 기준.
9. [시험 기준](CAPACITY.md), [실행 절차](CAPACITY_RUNBOOK.md), [검증 현황](CAPACITY_RESULTS.md): 재사용 가능한 시험과 확인된 범위.

## 시행착오 기록

[개발 사례](engineering/README.md)는 문제·대안·판단·검증을 설명하는 별도 문서 묶음이다.
기획과 현재 동작의 기준은 위 현행 문서를 따른다.
