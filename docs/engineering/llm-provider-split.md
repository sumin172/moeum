# 무료 티어 안에서 LLM 공급자를 용도별로 나누기

## 단일 공급자의 한계

대화와 일기는 처음에 모두 Gemini 3.1 Flash Lite 무료 API를 사용했다.
2026-10-24 프로젝트 화면의 한도는 RPM 약 15·입력 TPM 약 250,000·RPD 500이었다.
한 사람이 하루 대화 10회와 일기 1회를 쓰면 11회이므로 RPD 500으로 이론상 45명, 30% 여유를 두면 31명이다.
분당 15회는 몇 명이 동시에 대화해도 일기·재시도 여유가 거의 남지 않는 수준이었다.

같은 날 운영 응답기로 측정한 짧은 대화 응답은 약 2.9~7.1초였다.
대화 출력 상한 150토큰·thinking budget 0, 대화 프롬프트 v2, 재시도 없는 단일 호출 조건이다.
대표·부정·계획 변경 사례의 대화 6회는 모두 정상 종료했다.

## 용도별 분리

대화는 요청이 많고 짧으며 사용자가 답을 기다린다. 일기는 하루 한 번이며 입력이 크고 JSON 형식이 필요하다.
대화를 Cloudflare Workers AI의 Qwen3 30B A3B FP8로 옮기고 일기는 Gemini에 남겼다.
Gemini RPD는 일기에만 쓰이므로 하루 일기 약 40회 계획에 여유가 생긴다.
Gemini는 JSON 응답 형식을 강제할 수 있고, 구독 최대 입력 약 25만 토큰의 단일 호출 성공 표본이 있다.

LLM 호출은 purpose별 경로 설정으로 공급자를 고르는 구조였으므로,
전환은 Cloudflare 어댑터 추가와 conversation-response 경로 설정 변경이 중심이었다.
업무 모듈은 대화 프롬프트만 Qwen에 맞춰 v3로 조정했고 작업 실행 코드는 바뀌지 않았다.

## 분리 후 측정

2026-10-27 Qwen 대화 31회와 Gemini 일기 1회를 포함한 32회가 모두 정상 종료했다.
대화 지연은 463~1,486ms다. 실제 10턴 토큰에 공식 계수를 적용하면 약 42.2 Neurons이고,
같은 패턴 40명은 하루 약 1,689 Neurons로 무료량 10,000 Neurons 안에 계산된다.
말투 혼용·감정 추정·범위 이탈 요청 대응 같은 품질 제약이 함께 관측됐다. 현재 판정은 [검증 현황](../CAPACITY_RESULTS.md)을 따른다.

## 다시 검토할 때

Gemini를 대화에 다시 쓰려면 현재 대화 프롬프트로 지연·품질을 다시 측정한다. 위 Gemini 수치는 프롬프트 v2 기준이다.
공급자 간 자동 전환은 없다. 한 공급자의 장애를 다른 공급자로 넘기려면 프롬프트 호환성과 무료량을 함께 확인한다.
